# Demo runbook

## Five-minute flow

1. Start with **Strong - complete evidence** and point out the 0.31% estimate, high confidence, source coverage, and favorable factors.
2. Select **High risk - escalated review**, press **Evaluate case**, and show the 74.64% estimate plus adverse reason ledger. State that it is an enhanced human-review route, not a decline.
3. Select **Partial history - blended model** and show the frozen 75% history / 25% application blend plus data-limited route.
4. Select **Feature-store outage - fail closed** and show the missing-row quality flag and mandatory data-limited review even with a low point estimate.
5. Select **Affordability stress - what-if** and contrast the separate repayment-to-income screen with the model probability.
6. Open **Model evidence** and show 0.7849 ROC-AUC, 0.2799 average precision, 56.5% top-20% event capture, and all passed predeclared gates.
7. Open **Responsible AI** and close on the fairness caveats, prohibited uses, and production requirements.

## Mandatory wording

- Say "repayment-difficulty probability" rather than claiming an official credit-bureau score.
- Say "decision support" rather than autonomous lending.
- Label financial-loss figures as scenarios.
- Distinguish measured model results from synthetic demo assumptions.
- Explain that Kaggle data requires local-domain retraining before production.
